Kagami Media Tips

  • Photos: Exported as 1080×1080 baseline 4:2:0 JFIF JPEG (prevents hardware decoder green tint).
  • Circular Bezel: Keep faces & subjects inside the dashed ring.
  • Videos: Convert with ffmpeg:
ffmpeg -i input.mp4 \
  -vf "crop=min(iw\,ih):min(iw\,ih),scale=1080:1080:flags=lanczos" \
  -c:v libx264 -profile:v main -level 4.1 \
  -pix_fmt yuv420p -r 24 -b:v 6M -an \
  output_kagami.mp4
